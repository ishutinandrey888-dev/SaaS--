# Extension release checklist

## Локальная установка

- [ ] Открыть `chrome://extensions` или `browser://extensions`.
- [ ] Включить режим разработчика.
- [ ] Нажать `Загрузить распакованное расширение`.
- [ ] Выбрать папку `extension`.
- [ ] Убедиться, что расширение `Радар конкурентов` включено.
- [ ] Проверить, что `extension.pem` не лежит внутри папки публикации.
- [ ] Проверить, что `extension.crx` не лежит внутри папки публикации.

## Проверка Яндекс Поиска

- [ ] Открыть коммерческий запрос в Яндекс Поиске.
- [ ] Убедиться, что на странице есть блоки с меткой `Промо`.
- [ ] Нажать кнопку `Радар конкурентов`.
- [ ] Проверить, что собираются только промо-объявления Директа.
- [ ] Проверить домен рекламодателя.
- [ ] Проверить заголовок.
- [ ] Проверить описание.
- [ ] Проверить офферы: скидка, рассрочка, гарантия, бесплатный замер/консультация, калькулятор, квиз, цена, срочность, гео.
- [ ] Проверить инсайт `На что давит конкурент`.
- [ ] Проверить гипотезу `Что протестировать в своей рекламе`.
- [ ] Проверить `Сохранить в сводку`.
- [ ] Проверить `Получить полный AI-аудит`.
- [ ] Проверить `Создать рекламную кампанию с AI`.
- [ ] Проверить `Сохранить в сводку`.
- [ ] Проверить soft-gate после 3 сохраненных конкурентов.

## Проверка Wordstat

- [ ] Открыть `https://wordstat.yandex.ru`.
- [ ] Ввести запрос.
- [ ] Нажать `Радар Wordstat`.
- [ ] Проверить сбор видимых ключей.
- [ ] Проверить сбор частотности.
- [ ] Проверить intent: commercial, informational, brand, geo, mixed.
- [ ] Проверить выделение коммерческих запросов.
- [ ] Проверить выделение минус-слов.
- [ ] Проверить выделение смежных ниш.
- [ ] Проверить выделение запросов с высоким потенциалом.
- [ ] Проверить AI-подсказку по группам объявлений.
- [ ] Проверить сохранение ключей.

## Проверка popup

- [ ] Открыть popup по иконке расширения.
- [ ] Проверить счетчики конкурентов и ключей.
- [ ] Проверить выбор проекта.
- [ ] Проверить настройку Backend API URL.
- [ ] Проверить фильтр по офферу.
- [ ] Проверить список конкурентов.
- [ ] Проверить список ключей.
- [ ] Проверить HTML-экспорт.
- [ ] Проверить JSON-экспорт.
- [ ] Проверить soft-gate, если сохранено 3+ конкурента.

## Проверка sidepanel

- [ ] Проверить открытие sidepanel из Яндекс Поиска.
- [ ] Проверить fallback floating-panel, если sidepanel недоступен.
- [ ] Проверить сводку по текущему запросу.
- [ ] Проверить список конкурентов.
- [ ] Проверить офферы.
- [ ] Проверить слабые места/insight.
- [ ] Проверить идеи объявлений/hypothesis.
- [ ] Проверить кнопку `Сохранить в сводку`.
- [ ] Проверить текущую проверку Wordstat.
- [ ] Проверить сохраненные конкуренты и ключи.

## Проверка backend sync

- [ ] Запустить backend: `cd backend && npm run dev`.
- [ ] Проверить `GET http://localhost:8787/health`.
- [ ] В popup нажать `Подключить backend`.
- [ ] Проверить создание/получение проекта.
- [ ] Сохранить конкурентов и проверить `GET /projects/:projectId/competitors`.
- [ ] Сохранить ключи и проверить `GET /projects/:projectId/keywords`.
- [ ] Проверить `POST /radar/events`.
- [ ] Проверить `POST /radar/leads`.
- [ ] Проверить rate limit placeholder.
- [ ] Проверить ошибки в JSON-формате.

## Chrome Web Store / Яндекс.Браузер

- [ ] Подготовить production manifest.
- [ ] Проверить минимальные permissions.
- [ ] Проверить host permissions только для нужных доменов.
- [ ] Подготовить иконки нужных размеров.
- [ ] Подготовить privacy policy URL.
- [ ] Подготовить описание, скриншоты и видео.
- [ ] Проверить, что нет секретов и приватных ключей.
- [ ] Упаковать extension без dev-файлов.
- [ ] Проверить работу в чистом профиле браузера.
- [ ] Проверить работу без backend.
- [ ] Проверить работу с production backend.

## Legal/privacy

- [ ] Privacy policy описывает, какие данные собирает extension.
- [ ] Personal-data page описывает согласие на обработку ПДн.
- [ ] Terms описывают ограничения и demo/MVP-статус.
- [ ] Cookie policy нужна только для web-части, если используются cookies/analytics.
- [ ] Если контакт собирается внутри extension, есть checkbox согласия.
- [ ] В backend хранится только минимальный контакт: Telegram/email, consent, source, timestamp.
- [ ] Нет сохранения лишних персональных данных.
- [ ] Есть понятный способ удалить данные пользователя.
- [ ] Для production-хранения ПДн проверена 152-ФЗ модель: локализация, оператор ПДн, политика, согласие.

## Перед публикацией

- [ ] `node --check` проходит для JS-файлов extension и backend.
- [ ] Frontend build не сломан.
- [ ] Backend smoke-test проходит.
- [ ] Secret scan не находит токены/ключи.
- [ ] `.gitignore` содержит `extension.pem`, `extension.crx`, `.env`, `.env.*`, `node_modules`, `.next`, `*.log`.
- [ ] Финальный пакет не содержит `backend/data`, `.git`, `.env`, `.pem`, `.crx`, build caches.
