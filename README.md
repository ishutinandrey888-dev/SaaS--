# Радар конкурентов

MVP браузерного расширения для анализа конкурентов в Яндекс-поиске и сбора ключевых фраз из Wordstat.
Дополнительно в проект добавлен web lead-magnet MVP для сбора лидов в ДОЖИМ-АИ.

## Что уже есть

- Manifest V3 расширение без сборщика и внешних зависимостей.
- Кнопка `Радар конкурентов` в поиске Яндекса.
- Поиск видимых рекламных/коммерческих блоков на открытой странице.
- Извлечение домена, заголовка, описания и позиции.
- Автоматическое определение офферов: скидка, цена, гарантия, рассрочка, бесплатно, срочность, квиз, опыт.
- Кнопка `Радар Wordstat` на `wordstat.yandex.ru`.
- Сбор видимых ключевых фраз и частотности со страницы.
- Простая классификация интента: коммерческий, информационный, бренд/домен, смешанный.
- Popup расширения со списком сохраненных конкурентов и ключей.
- Активный проект в popup, к которому привязываются сохранения.
- Фильтр конкурентов по офферу.
- Переключатель `Только с гипотезами`.
- HTML-отчет по конкурентам, офферам, ключам и гипотезам.
- Брендинг ДОЖИМ-АИ с PNG-логотипом.
- Правая in-page панель для основного рабочего сценария в Яндекс Браузере.
- Backend-скелет API без внешних зависимостей.
- Web lead-magnet страница `frontend/app/radar/page.tsx`.
- Форма web-аудита: ниша, сайт, ключевые фразы, регион.
- Результат web-аудита: конкуренты, офферы, слабые места, идеи для рекламы.
- Lead capture: Telegram/email, согласие на обработку ПДн, legal links.
- CTA `Получить полный AI-аудит в ДОЖИМ-АИ`.
- Backend endpoints для web lead-magnet и аналитики.
- Настройки backend в popup: URL API, demo-подключение, статус синхронизации.
- Автосинхронизация сохраненных конкурентов и ключей с backend, если он подключен.
- Локальное хранение в `chrome.storage.local`.
- Экспорт сохраненных данных в JSON.

## Как установить локально

1. Откройте Chrome.
2. Перейдите в `chrome://extensions`.
3. Включите `Developer mode`.
4. Нажмите `Load unpacked`.
5. Выберите папку `extension`.

## Как тестировать

1. Откройте поиск Яндекса с коммерческим запросом, например:
   `https://yandex.ru/search/?text=ремонт%20квартир%20москва`
2. Нажмите кнопку `Радар конкурентов` в правом верхнем углу страницы.
3. Проверьте найденные карточки и нажмите `Сохранить`.
4. Откройте `https://wordstat.yandex.ru/`.
5. Введите запрос и дождитесь загрузки результатов.
6. Нажмите `Радар Wordstat`, затем `Сохранить ключи в сводку`.
7. Откройте popup расширения через иконку в панели Chrome.
8. Укажите проект и нажмите `Собрать отчет`, чтобы скачать HTML-отчет.
9. Используйте фильтр оффера, чтобы быстро увидеть конкурентов с ценой, гарантией, рассрочкой или другим крючком.

## Подключение backend к расширению

1. Запустите backend:

```bash
cd backend
npm run dev
```

2. Откройте popup расширения.
3. Проверьте URL `http://localhost:8787`.
4. Нажмите `Подключить backend`.
5. После этого новые сохранения конкурентов и ключей будут отправляться в backend и оставаться локально в расширении.

## Рабочая панель

Кнопка `Радар конкурентов` на странице открывает правую рабочую панель внутри страницы. Это совместимый режим для Яндекс Браузера: нативный Chrome `side_panel` в нем требует feature flag `YandexSidePanel`, поэтому в manifest он отключен.

- текущая проверка;
- сохранение найденных конкурентов или ключей;
- активный проект;
- фильтр по офферу;
- сохраненные конкуренты и ключи;
- HTML-отчет.

## Backend

Backend находится в папке `backend` и пока работает без базы данных, сохраняя данные в `backend/data/radar.json`.

Запуск:

```bash
cd backend
npm run dev
```

API:

- `GET /health`
- `POST /auth/demo`
- `GET /projects`
- `POST /projects`
- `GET /projects/:projectId/competitors`
- `POST /projects/:projectId/competitors`
- `GET /projects/:projectId/keywords`
- `POST /projects/:projectId/keywords`
- `POST /subscriptions/telegram`
- `POST /radar/scans`
- `GET /radar/scans/:id`
- `POST /radar/scans/:id/lead`
- `POST /analytics/events`

P0 endpoints используют JSON-хранилище, простую validation-логику и in-memory rate limit placeholder. Для production нужны база данных, auth, ограниченный CORS, полноценные rate limits и аудит согласий.

## Web lead-magnet

Frontend находится в папке `frontend` и реализован как минимальное Next.js приложение.

Запуск:

```bash
cd frontend
npm install
npm run dev
```

По умолчанию страница `http://localhost:3000/radar` обращается к backend `http://localhost:8787`.
Если backend запущен на другом URL, задайте:

```bash
NEXT_PUBLIC_RADAR_API_URL=http://localhost:8787 npm run dev
```

Страницы:

- `/radar` — lead-magnet MVP.
- `/register` — регистрация пользователя в локальный backend.
- `/dashboard` — MVP-кабинет после регистрации.
- `/admin` — premium SaaS админка для метрик, источников, UTM, рассылок и биллинга.
- `/analytics`, `/settings`, `/yandex` — заготовки внутренних разделов.
- `/privacy` — privacy placeholder.
- `/personal-data` — consent placeholder.
- `/terms` — terms placeholder.

Analytics events P0:

- `radar_page_view`
- `radar_scan_submitted`
- `radar_result_viewed`
- `radar_lead_submitted`
- `radar_full_audit_cta_clicked`

## Важные рамки

Расширение анализирует страницы, которые пользователь сам открыл. MVP не запускает массовый фоновый парсинг, не обходит капчи и не имитирует действия пользователя.
