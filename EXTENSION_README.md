# Радар конкурентов: browser extension

MVP-расширение ДОЖИМ-АЙ для быстрого анализа рекламы конкурентов в Яндекс Поиске и спроса в Wordstat. Расширение должно давать пользу без входа в SaaS: данные сохраняются локально, а подключение backend нужно только для синхронизации, лидов и событий.

## Текущий статус extension

### Где расширение встраивается

- Яндекс Поиск: content script `extension/src/content/yandex-search.js` на `yandex.ru/search`, `www.yandex.ru/search`, `ya.ru/search`.
- Wordstat: content script `extension/src/content/wordstat.js` на `wordstat.yandex.ru`.
- Popup: `extension/src/popup/*`, открывается по иконке расширения.
- Sidepanel: `extension/src/sidepanel/*`, открывается через `chrome.sidePanel`, если браузер поддерживает API; иначе content script показывает floating-panel.

### Какие данные собирает из Яндекс Поиска

Расширение ищет только рекламные блоки Яндекс Директа с меткой `Промо`.

Собирается:

- поисковый запрос;
- домен рекламодателя;
- заголовок;
- описание;
- позиция в выдаче;
- sitelinks;
- метка объявления;
- качество распознавания;
- офферы;
- инсайт `На что давит конкурент`;
- гипотеза `Что протестировать в своей рекламе`;
- время сбора.

Детектор офферов сейчас выделяет:

- скидка;
- рассрочка;
- гарантия;
- бесплатный замер/консультация;
- калькулятор/расчет/смета;
- квиз/подбор;
- цена;
- срочность;
- гео;
- опыт.

### Какие данные собирает из Wordstat

Wordstat content script собирает видимые строки с фразами и частотностью.

Собирается:

- исходный запрос;
- ключевая фраза;
- частотность;
- intent: `commercial`, `informational`, `brand`, `geo`, `mixed`;
- сигналы: коммерческий запрос, минус-слово, смежная ниша, высокий потенциал;
- AI-подсказка по группе объявлений;
- время сбора.

### Как работает popup

Popup показывает локальную базу по активному проекту:

- счетчики конкурентов и ключей;
- активный проект;
- Backend API URL;
- статус backend sync;
- фильтр по офферу;
- список конкурентов;
- список ключей;
- экспорт HTML-отчета;
- экспорт JSON;
- soft-gate после 3 сохраненных конкурентов.

### Как работает sidepanel

Sidepanel показывает рабочий экран:

- текущая проверка из Яндекс Поиска или Wordstat;
- сводка по текущему запросу;
- список найденных конкурентов или ключей;
- офферы, слабые места и идеи объявлений;
- кнопка `Сохранить в сводку`;
- soft-gate с переходом в ДОЖИМ-АЙ;
- сохраненные конкуренты и ключи по проекту;
- экспорт HTML-отчета.

### Как сохраняются конкуренты

Локальное хранилище: `chrome.storage.local`, ключ `competitorRadarState`.

Внутри хранятся:

- activeProject;
- apiBaseUrl;
- appBaseUrl;
- syncStatus;
- latestScan;
- competitors;
- keywords;
- leads;
- events.

Дедупликация идет по связке `source + query + domain + title + phrase`. Конкуренты ограничены последними 200 записями, ключи - последними 300.

### Как работает backend sync

Backend URL по умолчанию: `http://localhost:8787`.

Popup/sidepanel могут подключить backend:

1. `POST /auth/demo`;
2. `GET /projects`;
3. при необходимости `POST /projects`;
4. синхронизация конкурентов в `POST /projects/:projectId/competitors`;
5. синхронизация ключей в `POST /projects/:projectId/keywords`;
6. лиды в `POST /radar/leads`;
7. события в `POST /radar/events`.

Расширение не требует SaaS-логина для базовой пользы. Backend sync является добровольным.

### Что не работает или требует проверки

- DOM Яндекса меняется: селекторы нужно регулярно проверять на реальных запросах.
- `chrome.sidePanel` может не работать в некоторых версиях Яндекс.Браузера без feature flag; fallback floating-panel остается.
- Нет production auth: backend пока demo/local.
- Нет настоящего AI-анализа, используется rule-based классификация.
- Нет полноценной формы лида внутри extension с явным checkbox согласия; soft-gate ведет в web-flow ДОЖИМ-АЙ.
- Нет подписки на регулярный мониторинг из extension.

### Что мешает использовать extension как lead-generation инструмент

- Нужен явный lead capture в extension или стабильный переход в web lead-magnet с UTM.
- Нужна юридически аккуратная форма согласия, если контакт собирается внутри extension.
- Нужен production backend с auth, лимитами, логированием и хранением в БД.
- Нужна проверка публикации в Chrome Web Store и Яндекс.Браузере.
- Нужна стабильная метрика: открытие панели, сохранение конкурента, soft-gate view, CTA click, lead submit.

## Как запустить локально

1. Запустить backend:

```bash
cd backend
npm run dev
```

2. Открыть страницу расширений:

- Chrome: `chrome://extensions`;
- Яндекс.Браузер: `browser://extensions`.

3. Включить режим разработчика.

4. Нажать `Загрузить распакованное расширение`.

5. Выбрать папку `extension`.

## Как проверить Яндекс Поиск

1. Открыть `https://yandex.ru/search/?text=купить+квартиру+в+москве`.
2. Убедиться, что в выдаче есть объявления с меткой `Промо`.
3. Нажать `Радар конкурентов`.
4. Проверить:
   - количество промо-объявлений;
   - домены;
   - заголовки;
   - описания;
   - офферы;
   - инсайт;
   - гипотезу;
   - кнопку `Сохранить в сводку`;
   - CTA `Получить полный AI-аудит`;
   - CTA `Создать рекламную кампанию с AI`.

## Как проверить Wordstat

1. Открыть `https://wordstat.yandex.ru`.
2. Ввести коммерческий запрос, например `ремонт квартир москва`.
3. Нажать `Радар Wordstat`.
4. Проверить:
   - видимые ключи;
   - частотность;
   - intent;
   - коммерческие запросы;
   - минус-слова;
   - смежные ниши;
   - высокий потенциал;
   - AI-подсказки по группам объявлений.

## Compliance/security MVP

- Секреты в extension не нужны.
- Backend URL настраивается в popup.
- Локально хранятся только данные анализа, проект, настройки sync и добровольно сохраненные лиды.
- `extension.pem` и `extension.crx` должны быть в `.gitignore` и не попадать в публикационный пакет.
- Для сбора контакта нужен явный checkbox согласия и ссылки на privacy/personal-data/terms.
- Не сохранять лишние персональные данные: email/Telegram достаточно.
